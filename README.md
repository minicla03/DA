# 🚗 Smart Mobility & Traffic Analysis

This Data Analytics project focuses on analyzing urban traffic data to identify mobility patterns and critical zones, aiming to support decisions for smarter and more sustainable mobility.

## 📂 Repository Structure

The repository contains the following files:

*   **`smart_mobility_dataset.csv`**: The raw dataset used for the analysis. It contains measurements and data related to traffic and mobility.
*   **`SmartMobilityDA.ipynb`**: The main Jupyter notebook. It contains all the Python code used for:
    *   Data cleaning and preprocessing.
    *   Exploratory Data Analysis (EDA).
    *   Data visualization and geospatial analysis.
*   **`mappa_zone_critiche.html`**: An interactive map (generated by the notebook) that visually highlights the "critical zones" (e.g., areas with higher congestion or accident rates). It can be opened with any web browser.
*   **`DataAnalytics___Smart_Mobility_Traffic_Analysis.pdf`**: The final report/presentation summarizing the project, the methodologies used, and the main insights obtained from the analysis.

## 🚀 Getting Started

To explore the analysis or run the code locally:

1.  **Clone the repository** to your local machine:
    ```bash
    git clone <repo-url>
    ```
2.  **Requirements**: Ensure you have a Python environment set up (Python 3.8+ recommended). The main libraries required to run the notebook include:
    *   `pandas`
    *   `numpy`
    *   `matplotlib` / `seaborn`
    *   `folium` (or similar, for HTML map generation)
    *   `jupyter`
3.  **Run the Notebook**:
    Open the terminal in the project folder and run:
    ```bash
    jupyter notebook SmartMobilityDA.ipynb
    ```
4.  **View Results**:
    For a quick look at the results, you can directly open the `mappa_zone_critiche.html` file in your preferred web browser and read the PDF report `DataAnalytics___Smart_Mobility_Traffic_Analysis.pdf`.

## 📊 Project Objectives

*   Analyze mobility flows starting from the provided dataset.
*   Identify bottlenecks and highly critical zones.
*   Provide data-driven insights to improve traffic management and promote Smart Mobility.
